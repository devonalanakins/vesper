# Vesper — Terminal experience

**Experience goal:** an exceptionally polished, cinematic research instrument with verifiable states, clear reasoning and no fake live statistics.

Visual identity uses night ink, graphite/indigo surfaces, subtle atmospheric gradients, electric violet, mint and warm amber. Orbital mark suggests time, observation and controlled motion. Typography must be legible, tabular for financial quantities, restrained in layout but expressive in hierarchy. Keyboard focus, reduced motion and responsive layouts are mandatory.

## Surfaces

1. Overview: performance curve, sourced period, confidence and review statuses.
2. Research: hypotheses, experiment outcomes, execution/observation separation.
3. Risk: account scope, drawdown/exposure policy and gate status.
4. Evidence: origin, completeness, reconciliation and reproducibility.

## Source-truth rules

The initial terminal is fully **SYNTHETIC / NO ORDERS**. It includes real navigation, period controls and locally computed illustrative trend data. No fetches, no credentials, no real markets, no stored account info, no background requests and no real-time badges. Future private account data should be server-side scoped and include timestamp, completeness, source, permission and evidence links; unavailable states should never become zeros.

The first useful engineering increment is a mathematical evidence core plus accessible, read-only presentation. Later modules must be independently accepted rather than treated as implemented from design documents.
